# Radar 2.0: piano di implementazione

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Il radar delle competenze passa da ranghi relativi a unità vere con soglie fisse, stima lo slancio come tendenza su 6 mesi con margine d'errore, dichiara i dati incerti, cambia quadrante solo dopo due mesi di fila, e ogni competenza ha una sua pagina (`#competenze/{id}`) con andamento, risorse per iniziare e repository in crescita.

**Architecture:** La pipeline Python calcola tutto e scrive `radar.json` versione 2: la statistica sta in un modulo nuovo `pipeline/tendenza.py`, l'assemblaggio in `pipeline/radar.py` (riscritto), GitHub aggiunge una serie di base per l'AI e i repository nuovi più stellati, un passo nuovo `pipeline/risorse.py` controlla i link scelti a mano in `config/skills.yaml`. L'app Svelte legge solo la versione 2: `derive.ts` porta i valori veri in coordinate 0–1 su assi logaritmici a dominio fisso, il radar disegna lì, e la card Competenze mostra il radar oppure la pagina di una competenza (`SkillView.svelte`) in base all'elemento dell'indirizzo.

**Tech Stack:** Python 3.12 (pytest, requests, PyYAML); Svelte 5, TypeScript, Vite, d3, vitest + @testing-library/svelte, Playwright + axe.

**Spec:** `docs/superpowers/specs/2026-10-16-radar-2-design.md`

- [ ] **Step 3: Crea `pipeline/tendenza.py`**

```python
"""Tendenza di una quota nel tempo, con margine d'errore, e combinazione di più segnali.

Per ogni punto la quota è n / totale. La tendenza è una retta su log((n + 0,5) / totale),
pesata con n + 0,5: con conteggi di Poisson la varianza di log(n) è circa 1 / n, quindi i
punti con più casi contano di più. Se i punti sono più dispersi di quanto direbbe Poisson
(dispersione > 1), l'errore cresce di conseguenza (quasi-Poisson).
"""
from __future__ import annotations

import math

Z80 = 1.2816      # margine all'80%: ±1,28 errori standard
MAX_PESO = 2 / 3  # con almeno due segnali nessuno pesa di più
MIN_PUNTI = 4


def trend(xs: list[float], ns: list[float], totali: list[float]) -> dict | None:
    """Pendenza di log(quota) per unità di x, con il suo errore standard.

    I punti con totale 0 non entrano; con meno di MIN_PUNTI punti validi non c'è tendenza.
    """
    pts = [(x, n + 0.5, t) for x, n, t in zip(xs, ns, totali) if t]
    if len(pts) < MIN_PUNTI:
        return None
    ys = [math.log(w / t) for _, w, t in pts]
    sw = sum(w for _, w, _ in pts)
    xm = sum(w * x for x, w, _ in pts) / sw
    ym = sum(w * y for (_, w, _), y in zip(pts, ys)) / sw
    sxx = sum(w * (x - xm) ** 2 for x, w, _ in pts)
    if sxx == 0:
        return None
    b = sum(w * (x - xm) * (y - ym) for (x, w, _), y in zip(pts, ys)) / sxx
    disp = sum(w * (y - ym - b * (x - xm)) ** 2 for (x, w, _), y in zip(pts, ys)) / (len(pts) - 2)
    return {"pendenza": b, "errore": math.sqrt(max(disp, 1.0) / sxx)}


def _cap(w: list[float], cap: float) -> list[float]:
    """Taglia i pesi oltre `cap` e ridistribuisce il resto tra gli altri, in proporzione."""
    w = list(w)
    fixed: set[int] = set()
    while True:
        over = [i for i, x in enumerate(w) if i not in fixed and x > cap + 1e-12]
        if not over:
            return w
        fixed.update(over)
        free = [i for i in range(len(w)) if i not in fixed]
        left = 1 - cap * len(fixed)
        tot = sum(w[i] for i in free)
        for i in fixed:
            w[i] = cap
        for i in free:
            w[i] = w[i] * left / tot if tot else left / len(free)


def combine(trends: list[dict]) -> tuple[dict, list[float]] | None:
    """Media delle pendenze pesata per l'inverso della varianza, e i pesi usati.

    Con almeno due segnali nessun peso supera MAX_PESO: GitHub ha conteggi enormi
    e altrimenti deciderebbe da solo.
    """
    if not trends:
        return None
    inv = [1 / t["errore"] ** 2 for t in trends]
    w = [x / sum(inv) for x in inv]
    if len(w) >= 2:
        w = _cap(w, MAX_PESO)
    b = sum(wi * t["pendenza"] for wi, t in zip(w, trends))
    se = math.sqrt(sum((wi * t["errore"]) ** 2 for wi, t in zip(w, trends)))
    return {"pendenza": b, "errore": se}, w


def variazione(t: dict, mesi: float) -> float:
    """Variazione della quota in `mesi` mesi secondo la tendenza: 0,25 = +25%."""
    return math.exp(mesi * t["pendenza"]) - 1


def margine(t: dict, mesi: float) -> tuple[float, float]:
    """Estremi della variazione con il margine all'80%."""
    d = Z80 * t["errore"]
    return math.exp(mesi * (t["pendenza"] - d)) - 1, math.exp(mesi * (t["pendenza"] + d)) - 1


def rapporto(t: dict, mesi: float) -> float:
    """(1 + estremo alto) / (1 + estremo basso): 1 = nessuna incertezza.

    Si usa il rapporto e non la differenza perché la differenza cresce con la crescita stessa.
    """
    return math.exp(2 * mesi * Z80 * t["errore"])
```

```python
"""Controllo dei link «Per iniziare» di config/skills.yaml.

Una richiesta per link a settimana (HEAD, poi GET se il sito rifiuta HEAD). Un link è
segnato come non raggiungibile solo dopo due settimane di fila con errore: un sito può
cadere per qualche ora. Il passo non fa mai fallire il giro.
"""
from __future__ import annotations

import time
from datetime import date

from .common import log, read_json, redact, write_json

OUT = "risorse.json"
TIMEOUT = 15
PAUSA = 0.5


def check(s, url: str) -> int | None:
    """Stato HTTP finale del link, None se la richiesta non arriva."""
    try:
        r = s.head(url, allow_redirects=True, timeout=TIMEOUT)
        if r.status_code >= 400:  # alcuni siti rifiutano HEAD (403, 405): si riprova con GET
            r = s.get(url, timeout=TIMEOUT)
        return r.status_code
    except Exception as exc:  # noqa: BLE001 — rete, TLS, timeout: conta come errore, non ferma il giro
        log.warning("Risorse: %s non raggiungibile (%s)", url, redact(str(exc)))
        return None


def run(s, skills: list[dict], today: date) -> dict:
    old = (read_json(OUT, {}) or {}).get("link", {})
    week = today.isocalendar()[:2]
    out: dict[str, dict] = {}
    calls = 0
    for url in sorted({r["url"] for sk in skills for r in sk.get("risorse", [])}):
        prev = old.get(url)
        if prev and date.fromisoformat(prev["controllato"]).isocalendar()[:2] == week:
            out[url] = prev
            continue
        stato = check(s, url)
        calls += 1
        errori = (prev or {}).get("errori", 0) + 1 if stato is None or stato >= 400 else 0
        out[url] = {"stato": stato, "errori": errori, "ok": errori < 2, "controllato": today.isoformat()}
        time.sleep(PAUSA)
    write_json(OUT, {"link": out})
    return {"link": len(out), "richieste": calls, "non_raggiungibili": sum(not v["ok"] for v in out.values())}
```

```python
"""Radar delle competenze, versione 2: unità vere, soglie fisse, margine d'errore.

Slancio: variazione negli ultimi 6 mesi interi della quota della competenza sul totale
dell'AI, stimata come tendenza (pipeline/tendenza.py) e combinando i segnali:
  * arXiv: paper che la citano / paper AI del mese;
  * GitHub: nuovi repository con il suo topic / nuovi repository AI del mese (la base è
    la somma dei topic github_base_topics di sources.yaml);
  * lavoro: annunci che la citano / annunci del Paese, se ci sono almeno 8 settimane di
    rilevazioni fatte con la stessa ricerca.
Domanda: annunci ogni 10mila, media tra i Paesi della rilevazione più recente.

Quadranti a soglie fisse: slancio > 0 (cresce più dell'AI), domanda >= 3 annunci ogni 10mila.
Il quadrante pubblicato cambia solo se il calcolo di due mesi di fila dà il quadrante nuovo.
Una competenza è incerta se il margine all'80% dello slancio è largo:
(1 + alto) / (1 + basso) > RAPPORTO_MAX.

Lo storico si ricalcola ogni volta: il punto di k mesi fa usa le serie fermate a k mesi prima
e le rilevazioni del lavoro di almeno 28 x k giorni prima. Dove la domanda manca (prima della
prima rilevazione) il quadrante usa la domanda del primo punto successivo che ce l'ha.
"""
from __future__ import annotations

from datetime import date

from .common import read_json, write_json
from .tendenza import combine, margine, rapporto, trend, variazione

OUT = "radar.json"
VERSIONE = 2
FINESTRA = 6            # mesi della tendenza
SOGLIA_SLANCIO = 0.0    # cresce più dell'AI nel suo complesso
SOGLIA_DOMANDA = 3.0    # annunci ogni 10mila, circa 1 su 3.300
# Tarato il 16/10/2026 su arXiv e GitHub con la base AI vera: incerte text-to-SQL 1,66, robotica 1,65,
# LLMOps 1,64, Governance 1,64; solide MCP 1,46, multimodali 1,46, RAG 1,20, agenti 1,10.
RAPPORTO_MAX = 1.55
MIN_GIORNI_LAVORO = 56  # 8 settimane di rilevazioni con la stessa ricerca
GIORNI_MESE = 30.44
POCHI = 100             # sotto questa media al mese il motivo dell'incertezza dice «pochi»
MAX_STORICO = 24

QUADRANTS = {
    "impara-ora": "Impara ora",
    "prova": "Da provare",
    "consolida": "Da consolidare",
    "osserva": "Tieni d'occhio",
}
ETICHETTE = {"arxiv": "paper", "github": "repository nuovi", "lavoro": "annunci"}


def quadrant(slancio: float | None, domanda: float | None) -> str | None:
    if slancio is None or domanda is None:
        return None
    up, high = slancio > SOGLIA_SLANCIO, domanda >= SOGLIA_DOMANDA
    return "impara-ora" if up and high else "prova" if up else "consolida" if high else "osserva"


def published(calcolati: list[str | None]) -> list[str | None]:
    """Quadrante pubblicato mese per mese: cambia solo se il calcolato è lo stesso per due mesi di fila."""
    out: list[str | None] = []
    for i, q in enumerate(calcolati):
        if q is None or i == 0 or calcolati[i - 1] is None or out[i - 1] is None:
            out.append(q)
        else:
            out.append(q if q == calcolati[i - 1] else out[i - 1])
    return out


# ------------------------------------------------------------------ segnali

def arxiv_signal(arx: dict, sid: str) -> dict | None:
    series, months = arx.get("series", {}), arx.get("mesi", [])
    if sid not in series or len(months) < FINESTRA:
        return None
    tot = series.get("_totale", {})
    last = months[-FINESTRA:]
    ns = [series[sid].get(m, 0) for m in last]
    return {
        "tendenza": trend(list(range(FINESTRA)), ns, [tot.get(m, 0) for m in last]),
        "media_mese": sum(ns) / FINESTRA,
        "mensile": [{"mese": m, "n": series[sid].get(m, 0), "totale": tot.get(m, 0)} for m in months],
    }


def github_signal(gh: dict, sid: str) -> dict | None:
    series, months, base = gh.get("topics", {}).get(sid), gh.get("mesi", []), gh.get("base", {})
    if series is None or not base or len(months) < FINESTRA:
        return None  # senza base dell'AI il conteggio grezzo non si confronta con gli altri segnali
    last = months[-FINESTRA:]
    ns = [series.get(m, 0) for m in last]
    return {
        "tendenza": trend(list(range(FINESTRA)), ns, [base.get(m, 0) for m in last]),
        "media_mese": sum(ns) / FINESTRA,
        "mensile": [{"mese": m, "n": series.get(m, 0), "base": base.get(m, 0)} for m in months],
    }


def _latest_by_country(snaps: list[dict]) -> dict[str, dict]:
    out: dict[str, dict] = {}
    for x in sorted(snaps, key=lambda x: x["data"]):
        out[x["paese"]] = x
    return out


def _days(a: str, b: str) -> int:
    return (date.fromisoformat(b) - date.fromisoformat(a)).days


def jobs_signal(jobs: dict, sid: str) -> dict | None:
    """Domanda di oggi, tendenza (se le rilevazioni bastano) e rilevazioni da disegnare.

    Valgono solo le rilevazioni fatte con la stessa ricerca della più recente del Paese:
    una ricerca cambiata non è confrontabile.
    """
    snaps = jobs.get("snapshots", [])
    latest = _latest_by_country(snaps)
    q = lambda x: x.get("query", {}).get(sid)  # noqa: E731
    shares = {c: 10000 * x["competenze"][sid] / x["totale"] for c, x in latest.items()
              if x.get("competenze", {}).get(sid) is not None and x.get("totale")}
    if not shares:
        return None
    newest = max(latest[c]["data"] for c in shares)
    same = [x for x in snaps if x["paese"] in shares and q(x) == q(latest[x["paese"]])
            and x.get("totale") and x.get("competenze", {}).get(sid) is not None
            and _days(x["data"], newest) <= FINESTRA * GIORNI_MESE]

    trends = []
    for c in shares:
        own = sorted((x for x in same if x["paese"] == c), key=lambda x: x["data"])
        if len(own) < 2 or _days(own[0]["data"], own[-1]["data"]) < MIN_GIORNI_LAVORO:
            continue
        t = trend([_days(own[0]["data"], x["data"]) / GIORNI_MESE for x in own],
                  [x["competenze"][sid] for x in own], [x["totale"] for x in own])
        if t:
            trends.append(t)
    comb = combine(trends)

    by_day: dict[str, dict[str, float]] = {}
    for x in same:
        by_day.setdefault(x["data"], {})[x["paese"]] = 10000 * x["competenze"][sid] / x["totale"]
    return {
        "tendenza": comb[0] if comb else None,
        "media": round(sum(shares.values()) / len(shares), 3),
        "it": round(shares["it"], 3) if "it" in shares else None,
        "ogni_10mila": {c: round(v, 2) for c, v in sorted(shares.items())},
        "data": newest,
        "rilevazioni": [{"data": d, "media": round(sum(v.values()) / len(v), 3), "it": round(v["it"], 3) if "it" in v else None}
                        for d, v in sorted(by_day.items())],
    }


# ------------------------------------------------------------------ una competenza in un mese

def _summary(t: dict | None) -> dict:
    if t is None:
        return {"variazione": None, "margine": None}
    lo, hi = margine(t, FINESTRA)
    return {"variazione": round(variazione(t, FINESTRA), 4), "margine": [round(lo, 4), round(hi, 4)]}


def _out_signal(kind: str, s: dict | None, peso: float) -> dict | None:
    if s is None:
        return None
    out = {**_summary(s["tendenza"]), "peso": round(peso, 3)}
    if kind == "lavoro":
        out.update({"rilevazioni": s["rilevazioni"], "ogni_10mila": s["ogni_10mila"], "data": s["data"]})
    else:
        out["mensile"] = s["mensile"]
    return out


def _perche(sig: dict, used: list[tuple[str, dict]]) -> str:
    """Il motivo dell'incertezza, dai segnali che da soli hanno un margine largo."""
    parts = []
    for kind, t in used:
        if rapporto(t, FINESTRA) <= RAPPORTO_MAX:
            continue
        n = sig[kind].get("media_mese")
        parts.append(f"pochi {ETICHETTE[kind]} ({round(n)} al mese)" if n is not None and n < POCHI
                     else f"{ETICHETTE[kind]} con andamento irregolare")
    return " e ".join(parts) if parts else "segnali con andamento irregolare"


def _row(sk: dict, arx: dict, gh: dict, jobs: dict) -> dict:
    sid = sk["id"]
    sig = {"arxiv": arxiv_signal(arx, sid), "github": github_signal(gh, sid), "lavoro": jobs_signal(jobs, sid)}
    used = [(k, s["tendenza"]) for k, s in sig.items() if s and s["tendenza"]]
    comb = combine([t for _, t in used])
    pesi = dict(zip([k for k, _ in used], comb[1])) if comb else {}
    slancio = lo_hi = perche = None
    incerto = False
    if comb:
        t = comb[0]
        slancio = round(variazione(t, FINESTRA), 4)
        lo, hi = margine(t, FINESTRA)
        lo_hi = [round(lo, 4), round(hi, 4)]
        incerto = rapporto(t, FINESTRA) > RAPPORTO_MAX
        perche = _perche(sig, used) if incerto else None
    lav = sig["lavoro"]
    return {
        "slancio": slancio,
        "slancio_margine": lo_hi,
        "domanda": lav["media"] if lav else None,
        "domanda_it": lav["it"] if lav else None,
        "incerto": incerto,
        "incerto_perche": perche,
        "segnali": {k: _out_signal(k, s, pesi.get(k, 0.0)) for k, s in sig.items()},
    }


# ------------------------------------------------------------------ storico e uscita

def _months_before(arx: dict, gh: dict, jobs: dict, k: int) -> tuple[dict, dict, dict]:
    """I dati come erano k mesi prima: serie senza gli ultimi k mesi, rilevazioni di almeno 28 x k giorni prima."""
    if k == 0:
        return arx, gh, jobs
    arx_p = {**arx, "mesi": arx.get("mesi", [])[:-k]}
    gh_p = {**gh, "mesi": gh.get("mesi", [])[:-k]}
    snaps = jobs.get("snapshots", [])
    if snaps:
        cutoff = date.fromordinal(date.fromisoformat(max(x["data"] for x in snaps)).toordinal() - 28 * k).isoformat()
        snaps = [x for x in snaps if x["data"] <= cutoff]
    return arx_p, gh_p, {**jobs, "snapshots": snaps}


def _publish(points: list[tuple[str, dict]], ids: list[str]) -> None:
    """Quadrante calcolato e pubblicato di ogni punto, dal più vecchio al più recente."""
    for sid in ids:
        later = None
        for _, rows in reversed(points):  # domanda mancante: quella del primo punto successivo che ce l'ha
            r = rows[sid]
            if r["domanda"] is not None:
                later = r["domanda"]
            r["calcolato"] = quadrant(r["slancio"], r["domanda"] if r["domanda"] is not None else later)
        for (_, rows), q in zip(points, published([rows[sid]["calcolato"] for _, rows in points])):
            rows[sid]["pubblicato"] = q


def run(skills: list[dict], today: date) -> dict:
    arx = read_json("arxiv.json", {}) or {}
    if arx.get("completo") is False:  # giro interrotto: con poche serie i confronti sarebbero falsati
        arx = {}
    gh = read_json("github.json", {}) or {}
    jobs = read_json("jobs.json", {}) or {}
    links = (read_json("risorse.json", {}) or {}).get("link", {})

    points: list[tuple[str, dict]] = []  # dal più recente al più vecchio, poi girati
    for k in range(MAX_STORICO):
        a, g, j = _months_before(arx, gh, jobs, k)
        months = max(a.get("mesi", []), g.get("mesi", []), key=len)
        if len(months) < FINESTRA:
            break
        rows = {sk["id"]: _row(sk, a, g, j) for sk in skills}
        if all(r["slancio"] is None for r in rows.values()):
            break
        points.append((months[-1], rows))
    if not points:
        raise ValueError("radar vuoto: mancano sia arXiv sia GitHub")
    points.reverse()
    _publish(points, [sk["id"] for sk in skills])

    now = points[-1][1]
    prev = points[-2][1] if len(points) > 1 else {}
    out_rows = []
    for sk in skills:
        sid = sk["id"]
        r, p = now[sid], prev.get(sid, {})
        out_rows.append({
            "id": sid,
            "nome": sk["nome"],
            "breve": sk.get("breve", sk["nome"]),
            "plurale": bool(sk.get("plurale", False)),  # per accordare il verbo: «Multimodali entrano»
            "descrizione": sk.get("descrizione", ""),
            "slancio": r["slancio"],
            "slancio_margine": r["slancio_margine"],
            "domanda": r["domanda"],
            "domanda_it": r["domanda_it"],
            "quadrante": r["pubblicato"],
            "quadrante_calcolato": r["calcolato"],
            "incerto": r["incerto"],
            "incerto_perche": r["incerto_perche"],
            "slancio_prec": p.get("slancio"),
            "domanda_prec": p.get("domanda"),
            "quadrante_prec": p.get("pubblicato"),
            "segnali": r["segnali"],
            "per_iniziare": [{"lingua": "en", **x} for x in sk.get("risorse", []) if links.get(x["url"], {}).get("ok", True)],
            "in_crescita": gh.get("in_crescita", {}).get(sid, []),
        })

    write_json(OUT, {
        "versione": VERSIONE,
        "generato": today.isoformat(),
        "soglie": {"slancio": SOGLIA_SLANCIO, "domanda": SOGLIA_DOMANDA, "rapporto_max": RAPPORTO_MAX},
        "quadranti": QUADRANTS,
        "competenze": out_rows,
        "storico": [{"mese": m, "competenze": {sid: {k: r[k] for k in ("slancio", "domanda", "calcolato", "pubblicato", "incerto")}
                                                for sid, r in rows.items()}} for m, rows in points],
    })
    return {"competenze": len(out_rows), "posizionate": sum(1 for r in out_rows if r["quadrante"]),
            "incerte": sum(1 for r in out_rows if r["incerto"])}
```

```ts
export const MOVE_MIN = 0.1; // spostamento minimo per disegnare una freccia: un decimo dell'asse
/** Domini fissi degli assi, simmetrici attorno alle soglie: slancio 0 e 3 annunci ogni 10mila stanno al centro. */
export const SLANCIO_DOM: [number, number] = [-0.5, 1];
export const DOMANDA_DOM: [number, number] = [0.1, 90];
const unit = (v: number) => Math.min(1, Math.max(0, v));
const lin = (v: number, [a, b]: [number, number]) => (v - a) / (b - a);
/** Posizione 0–1 sull'asse dello slancio: scala logaritmica di 1 + slancio. */
export const nx = (s: number): number =>
  unit(lin(Math.log(1 + s), [Math.log(1 + SLANCIO_DOM[0]), Math.log(1 + SLANCIO_DOM[1])]));
/** Posizione 0–1 sull'asse della domanda: scala logaritmica. */
export const ny = (d: number): number => unit(lin(Math.log(d), [Math.log(DOMANDA_DOM[0]), Math.log(DOMANDA_DOM[1])]));

export interface RadarRowM extends RadarRow {
  breve: string;
  slancio: number;
  domanda: number;
  quadrante: Quadrant;
  incerto: boolean;
  /** Il quadrante calcolato, se diverso da quello pubblicato: la competenza ci si sta muovendo. */
  moving: Quadrant | null;
  x: number; // posizione sul grafico, 0–1
  y: number;
  px: number | null; // posizione di un mese fa (senza la domanda di allora si usa quella di oggi)
  py: number | null;
  sp: number | null;
  dp: number | null;
  qp: Quadrant | null;
  dS: number;
  dD: number;
  move: number;
  dC: number;
  changed: boolean;
  hasPrev: boolean;
}

export function radarRows(r: Radar): RadarRowM[] {
  if (r.versione !== 2) return []; // radar.json della pipeline vecchia: ranghi, non unità vere
  return r.competenze
    .filter((c) => c.slancio != null && c.domanda != null && c.quadrante != null)
    .map((c) => {
      const s = c.slancio as number, d = c.domanda as number;
      const sp = c.slancio_prec ?? null, dp = c.domanda_prec ?? null, qp = c.quadrante_prec ?? null;
      const hasPrev = sp != null;
      const x = nx(s), y = ny(d);
      const px = hasPrev ? nx(sp as number) : null;
      const py = hasPrev ? ny(dp ?? d) : null;
      // Senza domanda di un mese fa il movimento è solo sullo slancio.
      const dS = px != null ? x - px : 0;
      const dD = hasPrev && dp != null ? y - ny(dp) : 0;
      const calc = c.quadrante_calcolato ?? null;
      return {
        ...c, breve: c.breve || c.nome, slancio: s, domanda: d, quadrante: c.quadrante as Quadrant,
        incerto: !!c.incerto, moving: calc && calc !== c.quadrante ? calc : null,
        x, y, px, py, sp, dp, qp, dS, dD, move: Math.max(Math.abs(dS), Math.abs(dD)), dC: (dS + dD) / 2,
        changed: hasPrev && qp != null && qp !== c.quadrante, hasPrev,
      };
    });
}
```

```markdown
## Come si legge il radar

Ogni competenza ha due coordinate in unità vere:

- **Slancio**: quanto è cambiata negli ultimi 6 mesi interi la sua quota sul totale dell'AI, per esempio "+25% in 6 mesi". Si stima con una retta sui dati di ogni mese, combinando
  - la quota di paper AI su arXiv che la citano nell'abstract,
  - la quota di nuovi repository GitHub con il suo topic sui nuovi repository AI (somma dei topic `llm`, `ai`, `artificial-intelligence`, `generative-ai`),
  - la quota di annunci di lavoro che la citano, quando ci sono almeno 8 settimane di rilevazioni con la stessa ricerca.

  I segnali più precisi pesano di più, nessuno più di due terzi.
- **Domanda**: annunci di lavoro che la citano ogni 10.000 annunci attivi, in media tra i Paesi.

I quadranti hanno **soglie fisse**: slancio sopra 0 (cresce più dell'AI nel suo complesso) e almeno 3 annunci ogni 10mila. **Impara ora** (entrambe), **Da provare** (solo lo slancio), **Da consolidare** (solo la domanda), **Tieni d'occhio** (nessuna delle due). Aggiungere o togliere una competenza non sposta le altre.

Il radar è **prudente**: il quadrante cambia solo se il calcolo di due mesi di fila dà il quadrante nuovo; nel frattempo la competenza è "in movimento verso" il quadrante nuovo. Una competenza è **incerta** (punto vuoto) quando il margine d'errore dello slancio è largo, di solito per pochi paper o repository: resta sul radar ma non finisce nelle notizie della home.

Ogni competenza ha una sua pagina (`#competenze/mcp`) con l'andamento dei tre segnali, il percorso sul radar, le risorse per iniziare scelte a mano e i repository nuovi più stellati.

Limiti da tenere a mente:

- le ricerche sono per parole chiave, quindi un termine ambiguo può gonfiare o sgonfiare un conteggio;
- i topic GitHub li sceglie chi crea il repository;
- negli annunci in Italia, Germania o Francia le parole tecniche inglesi sono comuni ma non universali, quindi il confronto tra Paesi va letto con cautela.
```
